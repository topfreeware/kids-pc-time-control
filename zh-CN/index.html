KIDS PC TIME CONTROL

一家人共用的电脑时间管理工具：每日计划、当天临时规则、休息提醒和到时锁屏，家长与儿童使用独立的本地账号。

Windows 11 24H2 或更新版本 · x64 电脑 · 本地家长与儿童账号

在 Microsoft Store 查看 Kids PC Time Control

Kids PC Time Control 帮助家庭管理共用 Windows 电脑的使用时间。家长与儿童共用一个直观界面，通过不同的本地账号登录，无需注册 Kids PC Time Control 网络账号。

家长可以设置每天的总时长、单次连续使用上限、休息时长和禁止使用时段，支持跨午夜时段，并可随时修改规则。当天临时设置可分别替代每日总时长、单次上限或禁用时段；到本地时间午夜自动恢复日常安排，不会清空已经使用的时间。

儿童登录后自动计时。默认提前三分钟提醒，家长可以修改提醒时间。达到时限或进入禁用时段时，软件请求 Windows 锁屏，不会关机。请在到时前保存工作。家长可查看近期每天的使用记录，也可重设儿童密码。

可选的开机保护功能会在当前 Windows 账号登录或解锁后，要求在 60 秒内登录 Kids PC Time Control。该功能依赖 Windows 允许应用自启动，不替代 Windows 登录，不保护其他 Windows 账号，也不能防止管理员绕过软件。

家庭账号、规则和使用记录保存在本机，无广告、无使用分析、无云同步。界面支持简体中文、繁体中文、美国英语、德语、法语、西班牙语和日语。需要 Windows 11 24H2 或更新版本的 x64 电脑。

免费下载。家长可主动开启一次 7 天（168 小时）的完整功能试用，无需付款，不会自动扣费。试用后通过 Microsoft Store 应用内一次性购买完整版，计划美国价格为 US$8.89；以购买确认页显示的当地价格和税费为准。永久解锁，无订阅。试用结束且无有效购买授权时，时间控制和登录保护暂停，账号与设置保留。

购买和恢复购买需要 Microsoft Store 账号，不需要另建发布者网络账号。购买授权会定期核验；成功核验后，本地离线授权缓存最长 30 天，之后需要重新连接商店验证。
