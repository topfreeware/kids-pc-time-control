使用帮助与支持

首次启动创建家长账号，点击“开始 7 天免费试用”，再添加儿童账号并保存规则。试用或有效购买期间，儿童登录自动计时。 请先保存恢复码。完成前不会自动锁屏。

当天设置只替代您修改的项目。数字框留空代表沿用日常值；启用当天禁用时段覆盖但清空列表，代表今天没有禁用时段。临时规则到本地午夜失效，不会重置已使用时间。

需要开机保护时，在家长界面启用，并在 Windows 设置 → 应用 → 启动中允许 Kids PC Time Control。Windows 登录或解锁后，需要在 60 秒内登录 Kids PC Time Control。删除本地数据前请先停用保护。请保留 Windows 密码和恢复方式。

忘记家长密码时，在登录页点击“忘记家长密码？”，先输入并确认至少 6 位的新密码，再用保存的恢复码重设；恢复码也丢失时，可选择“通过 Windows 管理员恢复”，按 Windows 提示验证。儿童密码由家长重设。恢复成功后保留账号、规则和记录，旧恢复码失效；请保存新恢复码，再按需要启用开机保护。

反馈问题时请提供软件版本、Windows 版本、界面语言及复现步骤。GitHub 问题记录公开可见，请勿上传密码、family.db、儿童个人信息或私人截图。

使用 Microsoft Store 安装的版本购买完整版。恢复购买时，用原购买的 Microsoft Store 账号登录商店，再以家长身份点击“恢复购买”。取消购买不会新增授权或改变原授权。试用结束或核验失效会暂停保护，不会为了要求付款锁住电脑。恢复有效授权后，请家长按需要重新开启登录保护。

默认跟随 Windows 显示语言；不支持的系统语言使用英语，也可手动选择。

关闭窗口会保留后台计时；儿童切换账号时继续计时，直到新账号验证成功。应用运行且授权有效时，未登录需在 60 秒内完成认证。家长可选择“停用保护并退出”，停止计时、锁屏和自动启动。启用开机保护后，守护组件会重新启动异常结束的主程序；强行结束两个进程或卸载仍可能绕过保护。
