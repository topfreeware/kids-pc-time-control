用途與責任

Kids PC Time Control 由 Top Shareware 提供，請僅在您有權管理的電腦與 Windows 帳號上合法使用。成年人應設定家長帳號、向兒童說明限制，並保留恢復 Windows 存取的方式。請勿用於秘密監控或非法控制他人。

功能與限制

軟體執行本機時間規則並要求 Windows 鎖定畫面，不會關機。請提前儲存工作。開機保護為選用功能，僅適用目前的 Windows 帳號，依賴 Windows 自動啟動設定。它不取代 Windows 身分驗證，不構成對抗系統管理員的安全邊界，也不保證無法繞過。請妥善保管家長密碼。

授權與購買

本應用程式免費下載。家長主動開始 7 天完整功能試用，試用不會自動續訂或扣款。試用後可於應用程式內一次性購買完整版，永久解鎖，無訂閱；預定美國價格 US$8.89，實際金額以 Microsoft Store 確認頁為準。有效授權需定期驗證，離線快取最長 30 天。無有效授權時暫停時間控制及登入保護，保留本機資料。交易、還原購買及退款依適用的 Microsoft Store 條款辦理，退款或撤銷授權後付費功能可能停止。使用仍受本條款、第三方授權及強制適用法律約束，法定消費者權利不受影響。
