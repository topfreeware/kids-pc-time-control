使用說明與支援

首次啟動建立家長帳號，點選「開始 7 天免費試用」，再新增兒童帳號並儲存規則。試用或有效購買期間，兒童登入即自動計時。 請先儲存復原碼。完成前不會自動鎖定螢幕。

當天設定只取代您修改的項目。數字欄位留空代表沿用日常值；啟用當天禁用時段覆寫但清空清單，代表今天沒有禁用時段。臨時規則在本機午夜失效，不會重設已使用的時間。

需要開機保護時，請在家長介面啟用，並於 Windows 設定 → 應用程式 → 啟動允許 Kids PC Time Control。Windows 登入或解除鎖定後，須於 60 秒內登入 Kids PC Time Control。刪除本機資料前請先停用保護，並保留 Windows 密碼及復原方式。

忘記家長密碼時，在登入頁點選「忘記家長密碼？」，先輸入並確認至少 6 位的新密碼，再用保存的復原碼重設；復原碼也遺失時，可選擇「透過 Windows 管理員復原」，依 Windows 提示驗證。兒童密碼由家長重設。復原後保留帳號、規則和記錄，舊復原碼失效；請儲存新復原碼，再視需要啟用開機保護。

回報問題時請提供軟體版本、Windows 版本、介面語言及重現步驟。GitHub 問題紀錄公開可見，請勿上傳密碼、family.db、兒童個人資訊或私人螢幕擷取畫面。

使用 Microsoft Store 安裝的版本購買完整版。還原購買時，以原購買的 Microsoft Store 帳號登入商店，再以家長身分點選還原購買。取消購買不會新增或改變原有授權。試用結束或驗證失效會暫停保護，不會為了要求付款鎖住電腦。還原有效授權後，請家長依需要重新開啟登入保護。

預設跟隨 Windows 顯示語言；不支援的系統語言使用英語，也可手動選擇。

關閉視窗會保留背景計時；兒童切換帳號時繼續計時，直到新帳號驗證成功。應用程式執行且授權有效時，未登入須在 60 秒內完成驗證。家長可選擇「停用保護並結束」，停止計時、鎖定與自動啟動。啟用開機保護後，守護元件會重新啟動異常結束的主程式；強制結束兩個處理程序或解除安裝仍可能繞過保護。
