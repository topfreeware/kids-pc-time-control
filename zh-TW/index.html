KIDS PC TIME CONTROL

全家共用的電腦時間管理工具：每日計畫、當天臨時規則、休息提醒與到時鎖定，家長和兒童使用獨立的本機帳號。

Windows 11 24H2 或更新版本 · x64 電腦 · 本機家長與兒童帳號

在 Microsoft Store 查看 Kids PC Time Control

Kids PC Time Control 協助家庭管理共用 Windows 電腦的使用時間。家長與兒童共用一個直覺的介面，以不同的本機帳號登入，無須註冊 Kids PC Time Control 線上帳號。

家長可設定每日總時數、單次連續使用上限、休息時間及禁止使用時段，支援跨午夜時段，並可隨時修改。當天臨時設定可分別取代每日總時間、單次上限或禁用時段；本機時間午夜後自動恢復日常安排，不會清除已使用的時間。

兒童登入後自動計時。預設提前三分鐘提醒，家長可調整提醒時間。達到上限或進入禁用時段時，軟體要求 Windows 鎖定畫面，不會關機。請在到時前儲存工作。家長可檢視近期每日使用紀錄，也可重設兒童密碼。

可選的開機保護功能會在目前 Windows 帳號登入或解除鎖定後，要求於 60 秒內登入 Kids PC Time Control。此功能需要 Windows 允許應用程式自動啟動，不取代 Windows 登入，不保護其他 Windows 帳號，也無法阻止系統管理員繞過軟體。

家庭帳號、規則與使用紀錄儲存於本機，無廣告、無使用分析、無雲端同步。介面支援簡體中文、繁體中文、美式英文、德文、法文、西班牙文及日文。需要 Windows 11 24H2 或更新版本的 x64 電腦。

免費下載。家長可主動開始一次 7 天（168 小時）的完整功能試用，無須付款，不會自動扣款。試用後可透過 Microsoft Store 應用程式內一次性購買完整版，預定美國價格為 US$8.89；以購買確認頁顯示的當地價格與稅費為準。永久解鎖，無訂閱。試用結束且無有效購買授權時，時間控制與登入保護暫停，帳號及設定保留。

購買及還原購買需要 Microsoft Store 帳號，無須另建發行者線上帳號。購買授權會定期驗證；成功驗證後，本機離線授權快取最長 30 天，之後需要重新連線商店驗證。
