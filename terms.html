Kids PC Time Control is provided by Top Shareware for lawful use on computers and Windows accounts you are authorized to manage. Capabilities and limitations

Kids PC Time Control manages local time rules and requests Windows screen locking, not shutdown. Save your work before a limit is reached. Startup protection is optional, applies to the current Windows account and depends on Windows startup settings. It is not a replacement for Windows authentication, a security boundary against administrators, or a guarantee that use cannot be bypassed. Protect the parent password.
