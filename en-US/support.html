Support

On first launch, create a parent account, select Start 7-day free trial, then add a child account and save rules. Child sign-in starts timing during a valid trial or purchase license. Save a recovery code first. Automatic locking stays off until then.

Today's settings override only the values you change. Leaving a numeric field empty keeps its daily value. An enabled blocked-period override with an empty list means no blocked periods today. Today's overrides expire at local midnight and do not reset time already used.

To use startup protection, enable it in the parent interface and allow Kids PC Time Control in Windows Settings → Apps → Startup. After Windows sign-in or unlock, sign in to Kids PC Time Control within 60 seconds. Disable protection from the parent interface before removing local data. Keep your Windows password and recovery method available.

Forgot the parent password? First verify your recovery code or enter a Windows administrator account and password (not a PIN or the app password). After verification, enter the new parent password twice (6–64 characters) and save. Cancellation, returning to sign-in or expiry requires verification again. Use your recovery code if administrator password verification is unavailable. Recovery preserves accounts, rules and history and invalidates the old recovery code. Save a new code, then reenable startup protection if needed. To change a child's password, explicitly select that child in account management before entering a new password. Windows administrator credentials are handled briefly for local verification, never saved to the database or uploaded; password buffers are cleared after use.

For help, provide the app version, Windows version, interface language and steps to reproduce the issue. The linked GitHub issue tracker is public. Do not attach passwords, family.db, children's personal details or private screenshots.

Purchase using the Microsoft Store-installed version. To restore, sign in to Microsoft Store with the original purchasing account, then sign in as a parent and select Restore purchase. Cancelling does not add or change an existing license. An expired trial or unverified license pauses protection; the app never locks the PC to demand payment. After restoring a valid license, the parent can re-enable sign-in protection if needed.

Follows the Windows display language by default; unsupported languages fall back to English. Manual selection remains available.

Clicking X or pressing Alt+F4 minimizes to the taskbar and keeps the app running. Only a parent can close the app with Stop protection and exit. Closing the child window keeps timing in the background. Switching accounts keeps counting until the new sign-in succeeds. While the licensed app is running, an unsigned-in user has 60 seconds to sign in. A parent can select Stop protection and exit to stop timing, locking and automatic startup. With startup protection enabled, the companion restarts an unexpectedly terminated app. Force-ending both processes or uninstalling can still bypass protection.
