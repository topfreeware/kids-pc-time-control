KIDS PC TIME CONTROL

家族で使うパソコンの利用時間を管理。毎日の予定、今日だけの設定、休憩の通知、Windows の画面ロックを、保護者と子どものローカルアカウントで利用できます。

Windows 11 24H2 以降 · x64 パソコン · 保護者と子どものローカルアカウント

Microsoft Store で Kids PC Time Control を見る

Kids PC Time Control は、家族で共有する Windows パソコンの利用時間を管理するアプリです。保護者と子どもが、別々のローカルアカウントで同じ分かりやすい画面を使います。Kids PC Time Control のオンラインアカウントは必要ありません。

1 日の合計時間、連続利用の上限、休憩時間、利用できない時間帯を設定できます。日付をまたぐ時間帯にも対応し、ルールはいつでも変更できます。今日だけの設定では、合計時間、連続利用の上限、禁止時間帯をそれぞれ変更できます。現地時刻の午前 0 時に通常の設定へ戻り、使用済み時間は消えません。

子どもがログインすると自動で計測が始まります。初期設定では終了の 3 分前に通知し、保護者が通知時間を変更できます。上限に達した場合や禁止時間帯になった場合は、Windows に画面のロックを要求します。パソコンの電源は切りません。終了前に作業を保存してください。保護者は最近の日別利用履歴を確認し、子どものパスワードを再設定できます。

任意の起動時保護を有効にすると、現在の Windows アカウントへのサインインまたはロック解除後、60 秒以内に Kids PC Time Control へのログインが必要になります。Windows で自動起動が許可されている必要があります。Windows の認証を置き換えるものではなく、別の Windows アカウントは保護せず、管理者による回避も防げません。

家族のアカウント、ルール、利用履歴はこのパソコンに保存されます。広告、利用状況の分析、クラウド同期はありません。日本語、英語、簡体字中国語、繁体字中国語、ドイツ語、フランス語、スペイン語に対応。Windows 11 バージョン 24H2 以降の x64 パソコンが必要です。

ダウンロードは無料です。保護者の操作で、すべての機能を使える 7 日間（168 時間）の無料体験を 1 回開始できます。支払いや自動課金はありません。その後は Microsoft Store のアプリ内購入を 1 回行うと、完全版を永久に利用できます。米国での予定価格は US$8.89 です。地域の価格と税額は購入確認画面に表示されます。サブスクリプションではありません。体験終了後、有効な購入ライセンスがない場合は時間管理とログイン保護を一時停止し、アカウントと設定を保持します。

購入と復元には Microsoft Store アカウントが必要ですが、発行元の別アカウントは不要です。購入ライセンスは定期的に確認されます。確認後のローカルのオフラインライセンスキャッシュは最長 30 日間です。その後は Store に再接続して確認してください。

  • 保護者と子どもが別々のアカウントで同じ画面を利用
  • 1 日の合計時間と連続利用の上限を設定
  • 休憩時間と終了前の通知を調整
  • 日付をまたぐ時間帯を含む毎日の利用禁止設定
  • 午前 0 時に失効する今日だけの個別設定
  • 子どものログインで自動計測し、時間になると Windows をロック
  • 最近の日別利用履歴と子どものパスワード再設定
  • 現在の Windows アカウント向けの任意の起動時保護
  • 7 言語に対応し、クラウド同期なしでローカル保存
  • 全機能を 7 日間無料体験。1 回のアプリ内購入で永久利用、サブスクリプションなし
  • 標準では Windows の表示言語に従います。未対応の言語は英語を使用します。手動でも言語を選べます。
