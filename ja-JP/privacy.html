発行者と対象範囲

Kids PC Time Control は、家庭の共有パソコンを管理する成人向けに Top Shareware が提供するアプリです。本ポリシーは家庭向けアプリとその案内サイトに適用されます。保護者はルールを子どもに説明し、氏名ではなくニックネームの使用をお勧めします。

パソコンに保存する情報

ローカルの SQLite データベースに、アカウント名と役割、ソルト付きのパスワード派生値、ログイン失敗状態、時間ルール、表示言語、日付別の利用時間、休憩状態、時計の整合性情報を保存します。閲覧履歴、キー入力、文書、カメラやマイクの入力、他のアプリの内容は記録しません。パスワードには PBKDF2-SHA256、600,000 回の反復、個別のランダムなソルトを使用します。データベース全体は暗号化されていません。十分な Windows 権限を持つ人はローカルファイルを読み取り、変更できます。

利用目的・保存期間・共有

ローカルデータは、アカウント認証、時間ルールの適用、利用状況の表示に使います。日別履歴は最大 30 日分です。アカウントと設定は削除するまで、更新時のバックアップやコピーも利用者が削除するまで残ります。Kids PC Time Control は家族の記録を Top Shareware に送信せず、個人情報を販売しません。広告、利用分析、クラウド同期はありません。Windows と Microsoft Store はそれぞれのポリシーで情報を処理します。 最近 30 日分の履歴は、アプリが記録を新しい日に切り替える際に整理します。アプリを使わない場合、既存のファイルは次回の利用または手動での削除まで残る場合があります。

ウェブリンクとサポート

ウェブサイトを開く場合やサポートに連絡する場合、接続情報と利用者が送信した内容は各サービスに渡ります。この静的サイトは GitHub Pages で公開され、追加の分析、広告、フォーム、Cookie は使用していません。GitHub は独自のプライバシー声明に従って技術的な接続情報を処理する場合があります。GitHub の Issue は公開されます。パスワード、家族のデータベース、子どもを特定できる情報、非公開の画面画像を投稿しないでください。任意で提供されたサポート情報は問い合わせ対応に使います。

利用者による管理

保護者は最近の履歴を確認し、ルールの変更や子どものパスワード再設定ができます。すべてのローカルデータを消すには、先に保護者としてログインし、「保護を停止して終了」を選択してから、Family データフォルダーとバックアップやコピーを削除してください。通常の場所は %LOCALAPPDATA%\ScreenTimeControl\Family です。パッケージ版では Windows のパッケージ別ユーザーデータ領域を使う場合があります。これによりアカウントと設定が消えます。別に保存したコピーはアンインストール後も残る場合があります。発行者はパソコン内だけにあるデータを遠隔で閲覧、書き出し、削除できません。

連絡と変更

プライバシーに関する質問は、このページのサポートリンクから必要な情報だけを送信してください。子どもは保護者に連絡を依頼してください。データの取り扱いを変更する場合は、ポリシーと適用日を更新します。

無料体験と Microsoft Store での購入

利用可能な機能を判定するため、体験の開始・終了時刻、観測したパソコン時刻、購入確認状態、ライセンスキャッシュの有効期限も端末に保存します。アプリは Microsoft Store に本アプリと完全版アドオンのライセンスを問い合わせ、Store の購入画面を開きます。Microsoft は独自のポリシーに従って Store アカウント、決済、取引情報を処理します。本アプリはカード情報を受け取らず、家族のアカウント、時間ルール、利用記録を Microsoft に送信しません。
