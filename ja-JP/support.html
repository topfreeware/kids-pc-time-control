使い方とサポート

初回起動時に保護者アカウントを作り、7 日間の無料体験を開始してから、子どものアカウントとルールを追加します。有効な体験または購入ライセンスの期間中は、子どものログインで自動計測します。 先に復旧コードを保存してください。完了するまで自動ロックは無効です。

今日の設定は変更した項目だけに適用されます。数値欄を空にすると毎日の値を引き継ぎます。今日の禁止時間帯の上書きを有効にして一覧を空にすると、今日は禁止時間帯がなくなります。設定は現地時刻の午前 0 時に失効し、使用済み時間はリセットされません。

起動時保護は保護者画面で有効にし、Windows の設定 → アプリ → スタートアップで Kids PC Time Control を許可します。Windows へのサインインやロック解除後、60 秒以内に Kids PC Time Control にログインしてください。ローカルデータを削除する前に保護を無効にし、Windows のパスワードと回復方法を確保してください。

保護者のパスワードを忘れた場合は、まず回復コードを確認するか、Windows 管理者のアカウントとパスワード（PIN や本アプリのパスワードではありません）を入力してください。確認後、新しい保護者パスワード（6～64文字）を2回入力して保存します。キャンセル、ログイン画面への移動、期限切れの場合は再確認が必要です。管理者パスワードによる確認が利用できない場合は回復コードを使用してください。アカウント、ルール、履歴は保持され、古い回復コードは無効になります。新しいコードを保存し、必要に応じて起動時の保護を再度有効にしてください。お子様のパスワードを変更する際は、アカウント管理で対象のお子様を選択してから新しいパスワードを入力してください。Windows 管理者の認証情報はローカルでの確認のために一時的に処理され、データベースへの保存や送信は行いません。パスワードバッファーは使用後に消去します。

問い合わせにはアプリと Windows のバージョン、表示言語、再現手順を記載してください。GitHub の Issue は公開されます。パスワード、family.db、子どもの個人情報、非公開の画面画像を添付しないでください。

購入には Microsoft Store からインストールした版を使用します。復元するには、購入時の Microsoft Store アカウントで Store にサインインし、アプリで保護者として「購入を復元」を選びます。購入をキャンセルしても新しいライセンスは付与されず、既存のライセンスは変わりません。体験終了や確認できないライセンスでは保護を一時停止し、支払いを求めてパソコンをロックすることはありません。復元後、必要に応じて保護者がログイン保護を再度有効にしてください。

標準では Windows の表示言語に従います。未対応の言語は英語を使用します。手動でも言語を選べます。

X または Alt+F4 ではタスクバーに最小化され、アプリは動作を続けます。終了するには、保護者が「保護を停止して終了」を選択してください。 子どもの画面を閉じてもバックグラウンドで計測を続け、アカウント切替中も新しい認証が成功するまで継続します。有効なライセンスでアプリが動作中の場合、未ログインなら 60 秒以内にログインが必要です。保護者は「保護を無効にして終了」で計測、ロック、自動起動を停止できます。起動保護が有効なら、補助プログラムが予期せず終了した主アプリを再起動します。ただし、両方のプロセスの強制終了やアンインストールで回避される可能性があります。
