Aide et assistance

Au premier lancement, créez un compte parent, lancez l'essai gratuit de 7 jours, puis ajoutez un enfant et des règles. La connexion de l'enfant démarre le chronomètre pendant un essai ou une licence d'achat valide. Enregistrez d’abord un code de récupération. Le verrouillage automatique reste désactivé jusque-là.

Les réglages du jour remplacent uniquement les valeurs modifiées. Un champ numérique vide conserve la valeur quotidienne. Une exception de plages interdites activée avec une liste vide signifie qu'aucune plage n'est interdite aujourd'hui. Les exceptions expirent à minuit, heure locale, sans remettre le temps utilisé à zéro.

Activez la protection au démarrage dans l'interface parent et autorisez Kids PC Time Control dans Paramètres Windows → Applications → Démarrage. Après connexion ou déverrouillage de Windows, connectez-vous à Kids PC Time Control dans les 60 secondes. Désactivez la protection avant d'effacer les données locales. Conservez votre mot de passe Windows et un moyen de récupération.

Mot de passe parent oublié ? Vérifiez d’abord votre code de récupération ou saisissez un compte administrateur Windows et son mot de passe (pas un code PIN ni le mot de passe de l’application). Saisissez ensuite deux fois le nouveau mot de passe parent (6–64 caractères) et enregistrez-le. Après annulation, retour à la connexion ou expiration, recommencez la vérification. Si la vérification administrateur est indisponible, utilisez votre code de récupération. Les comptes, règles et historiques sont conservés ; l’ancien code est invalidé. Enregistrez un nouveau code, puis réactivez la protection au démarrage si nécessaire. Pour modifier le mot de passe d’un enfant, sélectionnez d’abord cet enfant dans la gestion des comptes. Les identifiants administrateur Windows sont traités brièvement pour une vérification locale, jamais enregistrés dans la base ni envoyés ; les tampons contenant le mot de passe sont effacés après utilisation.

Pour signaler un problème, indiquez les versions de l'application et de Windows, la langue et les étapes de reproduction. Les tickets GitHub sont publics. Ne joignez pas de mots de passe, de fichier family.db, de données personnelles d'enfants ni de captures privées.

Achetez dans la version installée depuis Microsoft Store. Pour restaurer, connectez le Store au compte ayant effectué l'achat, puis connectez-vous comme parent et choisissez Restaurer l'achat. Une annulation n'ajoute ni ne modifie de licence. L'expiration de l'essai ou une licence non vérifiée suspend la protection ; l'application ne verrouille jamais le PC pour exiger un paiement. Après restauration, le parent peut réactiver la protection de connexion si nécessaire.

Suit par défaut la langue d’affichage de Windows ; les langues non prises en charge utilisent l’anglais. Le choix manuel reste possible.

X ou Alt+F4 réduit l’application dans la barre des tâches ; elle continue de fonctionner. Seul un parent peut la fermer avec Arrêter la protection et quitter. Fermer la fenêtre enfant conserve le décompte en arrière-plan, y compris pendant le changement de compte jusqu’à une connexion réussie. Tant que l’application sous licence fonctionne, une personne non connectée dispose de 60 secondes pour se connecter. Un parent peut arrêter la protection et quitter pour cesser le décompte, le verrouillage et le démarrage automatique. La protection au démarrage relance l’application si elle est arrêtée de façon inattendue. Forcer l’arrêt des deux processus ou désinstaller peut contourner la protection.
